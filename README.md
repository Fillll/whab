# WHAB — We Have A Budget

The application lives in [`whab/`](whab/). Start with its [setup and usage guide](whab/README.md), [contribution guide](whab/CONTRIBUTING.md), and [plugin folder guide](whab/plugins/README.md).

Run development, test, packaging and launch commands from `whab/`:

```sh
cd whab
```

Each concrete plugin owns its implementation, assets, documentation and tests under `whab/plugins/<id>/`.
