# LLM categorization

An optional Automation plugin that proposes existing budget categories using an LLM. It is installed with the supported plugin set and **disabled by default**. Enable it instead of Random Forest for the selected budget, then restart WHAB when requested. Only one categorizer can be enabled per budget.

Open **Settings → Plugins → Installed → LLM categorization → Settings**:

1. Choose **OpenAI subscription**, **OpenAI API key**, **Anthropic API key**, or **OpenRouter API key**. OpenRouter already covers additional model providers; a generic custom endpoint is unnecessary for this version.
2. For a subscription, choose **Continue with ChatGPT**, open the sign-in link on the computer running WHAB, complete OpenAI's consent flow, and choose **Check sign-in**. Access depends on the account's eligible plan and granted plan-use permission. WHAB does not reuse browser cookies, passwords, or Codex credentials. For API providers, enter and save an API key; the key is never displayed again.
3. Choose **Load available models** and pick a model, or enter an exact model ID. Provider catalogs vary by account; an unavailable or non-text model produces an actionable error. Subscription models come from the account-specific catalog.
4. Name and save a prompt profile. Select how many recent reviewed examples to include (0–50), a minimum self-reported score (at least 0.8), and explicitly allow sending the described data. Zero examples works for a new budget with categories. Saving a profile prepares local context; it does not train or fine-tune a remote model or send transaction data.
5. Choose **Use profile**, then **Suggest for existing transactions**. Review the **LLM suggested** labels in Transactions, change or dismiss a suggestion, or accept the category and review together.

Automatic suggestions after bank imports are **off by default**. To enable them, save and select a profile with **Send eligible new transactions automatically after bank imports** checked. The selected profile's stored category catalog and examples remain fixed until a new profile is saved. Save a new profile after changing budget categories or to refresh examples. Disabling the plugin stops new requests and preserves its profiles and suggestion history.

## Data, credentials and safety

Each request sends category names/IDs, currencies, payee names (up to 200 characters), integer minor-unit amounts, and the selected reviewed examples. Transaction identities are replaced by request-local numbers. Account identifiers, dates, balances, notes, receipts, bank credentials and raw provider payloads are excluded. Subscription sign-in still uses OpenAI's cloud; it does not run a model on this computer. API usage can incur provider charges, and subscription usage consumes the plan's allowance. Manage ChatGPT app usage in [ChatGPT Settings](https://chatgpt.com/settings/usage).

Requests use fixed HTTPS provider endpoints with certificate verification, no redirects, no ambient proxy configuration and no automatic retries. Batches contain at most 20 eligible transactions. Successful imports remain saved if inference fails. The host retains currency, review, stale-suggestion and dismissal checks. Malformed responses, duplicate or foreign transaction IDs, unknown categories, mismatched currencies, non-finite scores, incomplete streams and below-cutoff guesses produce no applied category changes. Scores are model estimates, not calibrated confidence or measured accuracy. Responses never mark transactions reviewed or write actual categories.

Profiles, optional reviewed examples and opaque connection references belong to the budget's namespaced portable files. Demo uses a separate namespace. API keys and OAuth tokens live only in owner-only machine files under `~/.config/whab/llm-categorization/` (directory mode 0700, files 0600 on Unix). `LLM_CATEGORIZATION_CREDENTIALS_DIR` can explicitly select another machine-local directory. Keep that directory outside portable budgets and source control. Exports contain no credentials. On another machine, reconnect the provider before using an imported profile. Signing out revokes the renewable ChatGPT session when possible and clears local tokens; a failed remote revocation is reported explicitly.

The subscription integration follows [OpenAI's OSS sign-in flow](https://developers.openai.com/siwc/token-sharing-open-source/sign-in), including PKCE, random state and nonce, verified OIDC signature/issuer/audience/expiry, stable host identity, rotating refresh tokens, and explicit ChatGPT plan permission. As required by OAuth native-app registration, sign-in uses a separate ephemeral HTTP receiver bound only to `127.0.0.1` for `/auth/callback`. It accepts only the matching one-time sign-in state and Host, serves no application or financial data, logs no query strings, and closes on completion, cancellation, shutdown or five-minute expiry. **WHAB application and plugin settings routes continue to require HTTPS and local Host/origin checks.** The callback receiver is the native OAuth transport, not a WHAB financial route.

## Ownership and compatibility

Distribution: `whab_plugin_llm_categorization`, runtime ID: `llm-categorization`, Python 3.14+, WHAB 2.43+. The plugin owns providers, prompt profiles, credentials and its guarded settings transport. It uses only the public `whab.plugins` SDK. Its settings interface is local-only and coexists with the optional API interface plugin. Configure credentials on the authority computer. Remote ledger clients can request suggestions through the categorization command once the authority is configured; this version's credential settings must be opened locally on that authority. The plugin uses restart lifecycle because it owns credential and OAuth resources; it does not claim live worker upgrades.

From `whab/app/`, install with `.venv/bin/python scripts/install.py --dev`. Test with `.venv/bin/python -m pytest plugins/automation/llm-categorization/tests`. Tests use fictional records and mocked providers; no paid calls or private budgets are needed. See [contribution checks](../../../CONTRIBUTING.md#tests-and-checks) and [budget isolation](../../../../docs/architecture.md#budget-isolation-verification).
