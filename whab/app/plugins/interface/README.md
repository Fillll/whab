# Interface plugins

This category owns visual presentation, API interfaces and branding. Its independently packaged supported plugins are [Web](web/README.md), [Bank logos](bank-logos/README.md) and the [budget API server](server/README.md). A server transport is an API interface capability; it does not supply a visual page.

Keep each plugin's implementation, assets, tests and documentation in its own folder. See [plugin contribution rules](../README.md) for naming, SDK contracts and checks.
