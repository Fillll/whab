# Example plugins

This category owns teaching and reference plugins. The independently installable [example reporting/export plugin](example/README.md) lives in `example/` and keeps the plugin ID `example`.

This package is developer-only and hidden from ordinary Settings, including Options. Install and activate it with the [working-example instructions](../../docs/plugins.md#install-the-working-example). Examples follow the same implementation, asset, test, independent version and local changelog ownership rules as other plugins. See [plugin contribution rules](../README.md) for naming, SDK contracts and checks.
