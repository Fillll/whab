# WHAB repository

The application and its development instructions live in `whab/`. Read and follow [`whab/AGENTS.md`](whab/AGENTS.md) before changing application code, plugins, tests or documentation. Run application commands from `whab/`.

Keep credentials, runtime data and generated files out of Git. Stage reviewed source paths explicitly. Use a feature branch and pull request for changes to `main`.

Create version tags and GitHub releases only when the user explicitly requests a release. Version bumps and merges do not require publishing a release.
